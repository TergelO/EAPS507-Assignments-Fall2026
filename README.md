# Assignments for EAPS 507 – Fall 2026
This repository contains my completed assignments and in-class exercises for EAPS 507 during Fall 2026. These assignments focus on Python programming, numerical calculations, and scientific data analysis using Jupyter notebooks.

## Assignments
### 1. Assignment 01 – Madhava Pi Approximation
This assignment uses the Madhava series to calculate an approximation of pi. I tested different numbers of iterations, calculated the absolute error, and created a graph showing how the approximation becomes more accurate.

### 2. JupyterLab In-Class Exercise
This PDF contains my completed Python programming exercise from class. It includes Python functions, loops, and plotting using NumPy and Matplotlib.

### 3. Python Fundamentals Refresher
This exercise reviews basic Python programming, including functions, factorial calculations, variable scope, and loops. I also used NumPy and Matplotlib to create graphs.

### 4. Pandas Data Manipulation
This exercise focuses on using Pandas to work with geographic data from Indiana. It covers reading datasets, inspecting data, identifying missing values, and manipulating data using DataFrames.

### 5. Xarray Beginner Tutorial
This tutorial introduces Xarray for working with multidimensional scientific data. It covers creating datasets, selecting data, performing calculations, and plotting weather data.

### 6. Multidimensional Arrays Reading Summary
This PDF contains my reading summary about multidimensional arrays in NumPy. I explained why arrays are useful, how broadcasting works, and how arrays help organize and analyze scientific data.
